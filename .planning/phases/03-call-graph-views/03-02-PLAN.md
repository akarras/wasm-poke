2. Create helper function to build reverse graph (can be in app.rs or a utility module):
   ```rust
   /// Build reverse call graph: callee -> [callers]
   /// Used by Callers tree to show "who calls this function"
   fn build_reverse_graph(graph: &CallGraph) -> HashMap<u32, Vec<u32>> {
       let mut reverse: HashMap<u32, Vec<u32>> = HashMap::new();
       for (&caller, callees) in &graph.edges {
           for &callee in callees {
               reverse.entry(callee).or_default().push(caller);
           }
       }
       reverse
   }
   ```

3. Compute reverse graph in `load_wasm_from_path()` after building call_graph:
   ```rust
   // After: let call_graph = wasm_poke::build_call_graph(&bytes).ok();
   let reverse_graph = call_graph.as_ref().map(|cg| Self::build_reverse_graph(cg));

   // Store it:
   self.reverse_graph = reverse_graph;
   ```

4. Initialize reverse_graph as None in new():


5. Reset reverse_graph when loading new file (already covered by assignment in load_wasm_from_path).
