  <name>Task 1: Create CallTreePanel with tree rendering</name>
  <files>src/gui/panels/call_tree.rs, src/gui/panels/mod.rs</files>
  <action>
Create `src/gui/panels/call_tree.rs` with:

1. `CallTreePanel` struct with:
   - `filter_text: String` for search input
   - `filter_focused: bool` to track input focus

2. `show()` method signature matching FunctionListPanel pattern:
   ```rust
   pub fn show(
       &mut self,
       ctx: &egui::Context,
       ui: &mut egui::Ui,
       module: &WasmModuleInfo,
       call_graph: Option<&CallGraph>,
       selection: &mut SelectionState,
   )
   ```

3. Tree rendering with recursive helper:
   ```rust
   fn render_tree_node(
       ui: &mut egui::Ui,
       func_index: u32,
       depth: usize,
       path: Vec<(u32, usize)>,
       visited: &mut HashSet<u32>,
       module: &WasmModuleInfo,
       graph: &CallGraph,
       selection: &mut SelectionState,
   )
   ```

4. Use egui's `CollapsingState` for expand/collapse:
   - `CollapsingState::load_with_default_open(ctx, id, false)` for each node
   - Custom header with function name + size
   - `show_body_indented()` for children

5. Cycle detection:
   - Track `visited: HashSet<u32>` during traversal
   - Show "(recursive)" marker for cycles instead of re-expanding
   - IMPORTANT: Remove from visited set AFTER processing children (backtrack)

6. Depth limit:
   - `const MAX_DEPTH: usize = 5;`
   - Show "..." when exceeding depth limit

7. No selection case:
   - When no function selected, show message "Select a function to see its call tree"

8. Selection sync:
   - Clicking a function name in tree calls `selection.select_single(func_index)`

Update `src/gui/panels/mod.rs` to export CallTreePanel:
```rust
mod call_tree;
pub use call_tree::CallTreePanel;
```

Use `ByteSize::b(code_size).to_string_as(false)` for size display.
Use `module.functions.iter().find(|f| f.index == func_index)` to get function info.
For ID generation, use: `ui.make_persistent_id(("call_tree_node", path.clone()))`
