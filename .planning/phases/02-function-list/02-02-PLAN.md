<task type="auto">
  <name>Task 2: Implement FunctionListPanel</name>
  <files>src/gui/panels/function_list.rs</files>
  <action>
Create FunctionListPanel struct with:

**State fields:**
- `filter_text: String` - current filter input
- `sort_column: SortColumn` - enum { Name, Size, Calls }
- `sort_ascending: bool` - sort direction (default false for size = descending)
- `cached_indices: Vec<usize>` - indices into module.functions after filter/sort
- `cache_dirty: bool` - invalidate cache on filter/sort change

**SortColumn enum:**
```rust
#[derive(Clone, Copy, PartialEq, Eq, Default)]
pub enum SortColumn {
    Name,
    #[default]
    Size,
    Calls,
}
```

**Methods:**
- `pub fn new() -> Self` - default constructor
- `fn rebuild_cache(&mut self, module: &WasmModuleInfo, call_graph: Option<&CallGraph>)` - rebuild cached_indices based on filter and sort
- `fn count_calls(func_index: u32, call_graph: Option<&CallGraph>) -> usize` - count incoming calls to a function
- `pub fn show(&mut self, ui: &mut egui::Ui, module: &WasmModuleInfo, call_graph: Option<&CallGraph>, selection: &mut SelectionState)` - main render method

**show() implementation:**
1. Filter input with TextEdit::singleline at top
   - Track if filter changed to invalidate cache
   - Show match count: "N functions" or "N of M functions" when filtered
2. Check cache_dirty and rebuild if needed
3. Use egui_extras::TableBuilder with:
   - `.striped(true)` for alternating row colors
   - `.resizable(true)` for column resizing
   - `.sense(egui::Sense::click())` for row interaction
   - `.max_scroll_height(f32::INFINITY)` to fill available space
   - 3 columns: Name (auto, at_least 200, clip), Size (auto, at_least 80), Calls (auto, at_least 60)
4. Header row with clickable selectable_labels for sorting
   - Click toggles ascending/descending if same column, or switches column
   - Show sort indicator (arrow up/down) on active column
5. Body with `body.rows(ROW_HEIGHT, cached_indices.len(), |mut row| {...})`
   - Map row.index() to cached_indices[idx] to get function
   - Use `row.set_selected(is_selected)` for highlight
   - Name column: Label with truncate(), tooltip with full name
   - Size column: format with bytesize (ByteSize::b(size).display().iec_short().to_string())
   - Calls column: count of incoming calls

**Filtering:**
- Use `wasm_poke::function_matches(func, &self.filter_text)` for each function
- This reuses the existing globset-based filtering logic

**Sorting:**
- Name: sort by `func.best_name()` (case-insensitive)
- Size: sort by `func.code_size`
- Calls: sort by incoming call count
- Apply ascending/descending based on `sort_ascending`

**Row click handling (basic - single click only for now):**
- On `row.response().clicked()`, call `selection.select_single(func.index)`
- Ctrl+click and Shift+click will be added in Plan 02-03
  </action>
  <verify>Run `cargo check` to verify compilation.</verify>
  <done>FunctionListPanel renders a virtualized table with filter, sort, and basic click selection.</done>
