<task type="auto">
  <name>Task 2: Extend SelectionState for multi-select</name>
  <files>src/gui/state.rs</files>
  <action>
Replace the current SelectionState implementation with multi-select support:

1. Change `selected_function: Option<u32>` to `selected_functions: BTreeSet<u32>` (BTreeSet for ordered iteration)
2. Add `last_selected: Option<u32>` to track most recently selected (drives inspector in Phase 4)
3. Add `focus_index: Option<u32>` for keyboard navigation focus (may differ from selection)
4. Add helper methods:
   - `select_single(&mut self, index: u32)` - clears selection, selects one, updates last_selected and focus
   - `toggle_select(&mut self, index: u32)` - Ctrl+click behavior
   - `extend_select(&mut self, from: u32, to: u32)` - Shift+click range selection
   - `clear_selection(&mut self)` - clears all selection state
   - `is_selected(&self, index: u32) -> bool` - check if function is selected
   - `primary_selection(&self) -> Option<u32>` - returns last_selected (for inspector integration)

Use BTreeSet from std::collections (not HashSet) for deterministic ordering.

Keep the existing `instruction_cursor` and `expanded_nodes` fields unchanged.
  </action>
  <verify>Run `cargo check` to verify state.rs compiles.</verify>
  <done>SelectionState has multi-select fields and helper methods. App still compiles (though app.rs may show warnings about unused fields until Plan 02-02 integrates them).</done>
