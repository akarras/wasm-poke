<task type="auto">
  <name>Task 1: Add keyboard navigation</name>
  <files>src/gui/panels/function_list.rs</files>
  <action>
Add a `handle_keyboard` method to FunctionListPanel and call it from `show()`:

```rust
fn handle_keyboard(
    &self,
    ctx: &egui::Context,
    selection: &mut SelectionState,
    filtered_count: usize,
    visible_rows: usize,
) -> Option<usize>  // Returns new focus row if changed (for scroll_to_row)
```

**visible_rows calculation:**
Calculate visible_rows from ui.available_height() / ROW_HEIGHT where ROW_HEIGHT is the same constant used for table rows (typically 20.0). If calculation is not possible at the point of call, use a default of 20 rows.

```rust
const ROW_HEIGHT: f32 = 20.0;
let visible_rows = (ui.available_height() / ROW_HEIGHT).floor() as usize;
let visible_rows = visible_rows.max(1); // ensure at least 1
```

**Implementation:**
1. Early return None if filtered_count == 0 or filter TextEdit has focus
2. Get current focus position by mapping selection.focus_index to cached_indices position
3. Track shift modifier for range selection: `let shift = ctx.input(|i| i.modifiers.shift);`
4. Handle keys:
   - `Key::J` or `Key::ArrowDown`: move down 1
   - `Key::K` or `Key::ArrowUp`: move up 1
   - `Key::G` (without shift) or `Key::Home`: jump to top (index 0)
   - `Key::G` (with shift) or `Key::End`: jump to bottom (filtered_count - 1)
   - `Key::D` with Ctrl: half-page down (current + visible_rows / 2)
   - `Key::U` with Ctrl: half-page up (current - visible_rows / 2)
5. Clamp new_focus to valid range: 0..filtered_count
6. If new_focus changed:
   - Get function index from cached_indices[new_focus]
   - If shift held: call selection.extend_select(last, func_index)
   - Else: call selection.select_single(func_index)
   - Return Some(new_focus) for scroll
7. Else return None

**Integration in show():**
- Calculate visible_rows before calling handle_keyboard
- Call handle_keyboard before building the table
- Store the scroll_to target
- Pass it to TableBuilder with `.scroll_to_row(row, Some(egui::Align::Center))` if Some

**Filter focus check:**
Store the filter TextEdit response id and check:
```rust
let filter_id = ui.make_persistent_id("function_filter");
let filter_response = ui.add(egui::TextEdit::singleline(&mut self.filter_text).id(filter_id));
let filter_focused = filter_response.has_focus();
```

Only handle keyboard navigation when `!filter_focused`.

<task type="auto">
  <name>Task 2: Add multi-select click handling</name>
  <files>src/gui/panels/function_list.rs</files>
  <action>
Update the row click handling in show() to support Ctrl+click and Shift+click:

In the body.rows() closure, after getting the row response:

```rust
let response = row.response();
if response.clicked() {
    let modifiers = ui.input(|i| i.modifiers);
    let func_index = module.functions[cached_indices[idx]].index;

    if modifiers.ctrl || modifiers.command {
        // Ctrl+click (or Cmd on Mac): toggle selection
        selection.toggle_select(func_index);
    } else if modifiers.shift {
        // Shift+click: extend selection from last_selected to this
        if let Some(from) = selection.last_selected {
            // Need to find the range in cached_indices and select all in between
            // Find positions of 'from' and 'func_index' in cached_indices
            let from_pos = cached_indices.iter().position(|&i| module.functions[i].index == from);
            let to_pos = idx;
            if let Some(from_pos) = from_pos {
                let (start, end) = if from_pos <= to_pos { (from_pos, to_pos) } else { (to_pos, from_pos) };
                // Use extend_select_indices helper method for filtered list range
                let indices = (start..=end).map(|i| module.functions[cached_indices[i]].index);
                selection.extend_select_indices(indices);
                selection.focus_index = Some(func_index);
            } else {
                selection.select_single(func_index);
            }
        } else {
            selection.select_single(func_index);
        }
    } else {
        // Plain click: single select
        selection.select_single(func_index);
    }
}
```

Note: This uses the `extend_select_indices` helper added in Plan 02-01 Task 2, which accepts an iterator of function indices. This is necessary because the filtered/sorted list may not have contiguous indices, so we can't use the simple from..=to range of `extend_select`.

Also update `row.set_selected()` to check `selection.is_selected(func_index)`.
