<task type="auto">
  <name>Task 2: Create output generation module</name>
  <files>src/output.rs</files>
  <action>
Create `src/output.rs` with JSON and summary output generators:

1. Define JSON output structures (all derive Serialize):
   ```rust
   pub struct JsonOutput {
       pub functions: Vec<FunctionOutput>,
       pub call_graph: CallGraphOutput,
       pub summary: SummaryOutput,
   }

   pub struct FunctionOutput {
       pub index: u32,
       pub name: String,           // demangled (best_name)
       pub raw_name: Option<String>,
       pub code_size: u32,
       pub percentage: f64,
       pub exports: Vec<String>,
       #[serde(skip_serializing_if = "Option::is_none")]
       pub source: Option<SourceOutput>,
   }

   pub struct SourceOutput {
       pub file: String,
       pub start_line: u32,
       pub end_line: u32,
   }

   pub struct CallGraphOutput {
       pub edges: Vec<[u32; 2]>,  // [[src, dst], ...]
       pub functions_with_indirect: Vec<u32>,
   }

   pub struct SummaryOutput {
       pub total_code_size: u64,
       pub function_count: u32,
       pub imported_functions: u32,
       pub exported_functions: u32,
   }
   ```

2. Implement `build_json_output(module: &WasmModuleInfo, call_graph: &CallGraph, wasm_bytes: &[u8]) -> JsonOutput`:
   - Map each function to FunctionOutput with percentage
   - Include source span if available (use function_source_span)
   - Flatten call_graph.edges to Vec<[u32; 2]>
   - Collect functions with has_indirect = true

3. Implement `output_json(module: &WasmModuleInfo, call_graph: &CallGraph, wasm_bytes: &[u8], writer: &mut impl Write) -> anyhow::Result<()>`:
   - Build JsonOutput and serialize with serde_json::to_string_pretty
   - Write to provided writer

4. Implement `output_summary(module: &WasmModuleInfo, writer: &mut impl Write) -> anyhow::Result<()>`:
   - Header: "WebAssembly Module Summary"
   - Stats: function counts (defined, imported), total code size
   - Top 20 functions by size with percentage
   - Format: "  1. function_name - 1234 bytes (12.3%)"

Use wasm_poke crate for types and helper functions.
  </action>
