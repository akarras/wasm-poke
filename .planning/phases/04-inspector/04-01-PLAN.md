<task type="auto">
  <name>Task 2: Create InspectorPanel with WAT display and keyboard navigation</name>
  <files>src/gui/panels/inspector.rs, src/gui/panels/mod.rs</files>
  <action>
Create `src/gui/panels/inspector.rs` implementing InspectorPanel with:

1. **Struct definition with caching:**
```rust
pub struct InspectorPanel {
    /// Cached function index to detect selection changes
    cached_func_index: Option<u32>,
    /// Cached WAT lines for current function
    cached_wat_lines: Vec<wasm_poke::WatLine>,
    /// Cached function body bytes
    cached_hex_bytes: Vec<u8>,
}
```

2. **`new()` constructor** returning default empty state

3. **`update_cache()` method** that:
   - Takes `func_index: u32`, `module: &WasmModuleInfo`, `wasm_bytes: &[u8]`
   - Checks if `cached_func_index != Some(func_index)`
   - If changed: calls `disassemble_function_wat_lines()` and `function_body_bytes()`
   - Stores results in cached fields
   - IMPORTANT: Also reset `selection.instruction_cursor = 0` when function changes

4. **`handle_keyboard()` method** following function_list pattern:
   - Takes `ctx: &egui::Context`, `selection: &mut SelectionState`, `line_count: usize`
   - j/ArrowDown: increment cursor (capped at line_count - 1)
   - k/ArrowUp: decrement cursor (saturating_sub)
   - g: jump to 0
   - G (shift+g): jump to line_count - 1
   - Returns `Option<usize>` with new cursor position if changed (for scroll_to_row)

5. **`show()` method** with signature:
```rust
pub fn show(
    &mut self,
    ctx: &egui::Context,
    ui: &mut egui::Ui,
    module: &WasmModuleInfo,
    wasm_bytes: &[u8],
    selection: &mut SelectionState,
)
```

The show() method should:
- Check if `selection.last_selected` is Some; if None, show "Select a function"
- Call `update_cache()` with the selected function
- Handle keyboard input via `handle_keyboard()`
- Display WAT lines using ScrollArea with show_rows for virtualization

6. **WAT panel rendering:**
   - Use `ScrollArea::vertical().id_salt("wat_scroll")`
   - Use `show_rows()` with row_height ~18.0 for virtualization
   - For each line: check if `row_index == selection.instruction_cursor`
   - If current: paint background highlight using `ui.painter().rect_filled()` BEFORE adding label
   - Use `RichText::new(&line.text).monospace()` for display
   - Apply scroll_to_row when cursor changes via keyboard

7. **Highlight colors:**
   - Use `ui.visuals().selection.bg_fill` for highlight background (theme-aware)
   - Or define a constant like `Color32::from_rgba_unmultiplied(100, 100, 200, 40)`

Update `src/gui/panels/mod.rs` to add:
```rust
pub mod inspector;
pub use inspector::InspectorPanel;
```
